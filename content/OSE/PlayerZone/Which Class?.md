Which class should I pick based on my Stats? This page is organized by type of class- Usual classes and Unusual classes. Unusual classes require better stat rolls for the primary stats. The classes are then organized by which stat should be a strong/high stat to do well with that class. An Acrobat needs a high DEX, for example. 

If a second high stat is needed, it is included with (+STAT)



## Usual classes

### DEX
Acrobat, Assassin, Gnome (+INT), Halfling (+STR), Half Orc (+STR), Thief.
### STR
Barbarian (Benefits from +CON), Drow (+WIS), Duergar, Dwarf, Elf (+INT), Fighter, Half-Elf (+INT), Halfling (+DEX), Half Orc (+DEX), Knight, Paladin (+WIS), Ranger, Svirfneblin. 
### WIS
Cleric, Drow (+STR), Druid, Paladin (+STR).
### INT
Elf (+STR), Gnome (+DEX), Half-Elf (+STR), Illusionist, Magic User
### CHA
Bard
